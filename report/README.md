# LaTeX report project

Compile `main.tex` with a LaTeX engine that provides `pdfpages`, `graphicx`, `booktabs`, and `lmodern`. Figures live in `../images/`; the unchanged A1 report appendix is `appendices/A1_Report.pdf`. All result values in `main.tex` are generated from `outputs/results/results.json` by `run_all.py`.
